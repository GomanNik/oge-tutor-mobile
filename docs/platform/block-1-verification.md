# Блок 1: проверка и границы готовности

Дата исходной проверки: 2026-10-22. Дополнительная проверка: 2026-10-24. Среда: Windows, Docker Desktop, PostgreSQL 16-alpine, изолированные тестовые БД. Все адреса и аккаунты ниже относятся к локальной разработке. PR #2 объединён в `main` по прямому решению владельца при сохранении перечисленных ниже открытых проверок. Этот отчёт не разрешает промышленный rollout.

## Историческая проверка PR #2

| Область | Результат |
|---|---|
| Сборка и unit | `pnpm run quality`: backend build/lint, 64 unit-теста, frontend build/lint/typecheck, 29 UI/unit-тестов — успешно. Production frontend build выполнен с `VITE_API_BASE_URL=http://127.0.0.1:3001`. |
| HTTP и PostgreSQL | `pnpm run backend:test:e2e` на отдельной мигрированной PostgreSQL: 7 сценариев — успешно. Проверены v1 учебный поток, v2 администрирование, разделение двух пространств, ревизии, приглашения и повторная доставка, ограничения частоты, конкурентная защита последнего администратора, закрытие v1 при приостановке с сохранением доступа в другое v2-пространство. |
| Миграции | Пустая БД: `migrate deploy`, одноразовый bootstrap, повторный bootstrap без дублирования. Копия старой схемы: 2 преподавателя, 2 ученика (один отключён), 1 урок и 1 сессия; после миграции — 2 mapping, 2 пространства, 4 membership, 6 grants. | Ручной UI | На локальном API и SMTP Mailpit: вход администратора, список/управление участниками, приглашение через настоящее письмо, открытие ссылки, принятие новым аккаунтом, вход и проверка student-контекста, видимость нового участника администратором. Токен удаляется из URL после открытия. |
