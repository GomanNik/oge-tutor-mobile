# Блок 3: результаты локальной приёмки

Дата: 2026-10-24. Ветка: `codex/block3-courses` поверх открытого PR #4 (`codex/block1-block2-acceptance`). Эти результаты не означают слияние PR или развёртывание на VPS.

| Критерий | Результат |
|---|---|
| Миграция | Девять миграций развернулись на новой PostgreSQL. `test:migrations` прошёл fresh/legacy/replay и восстановление после backfill; `prisma migrate diff --exit-code` сообщил `No difference detected`. Preflight требует однозначного пространства, членств и действующих ролей; составные FK блокируют межпространственные связи. |
| Домен и HTTP | PostgreSQL e2e: 11/11. Проверены опубликованная и черновая версии, ОГЭ/ЕГЭ, два пространства, права трёх ролей, последний ведущий, смена состояний, ревизии, 24-часовая идемпотентность, вместимость, приватность ученика, атомарный массовый набор, конкуренция за последнее место. Реально вызванные v2-ответы проверены по OpenAPI. |
| Frontend | `pnpm run quality`: backend build/lint/64 unit, frontend build/lint/typecheck/38 unit. Playwright на реальном API: администратор создал групповой курс, активировал его, зачислил двоих, изменил цель без изменения статуса; ученик увидел только своё участие. Пройдено на 390 и 1365px без горизонтального переполнения. CI-подобный прогон после bootstrap и аддитивной fixture: 3/3 реальных browser smoke; автономный viewport/keyboard прогон: 3/3. |
| Сборка и зависимости | Оба Docker-образа собраны. `pnpm run audit` прошёл; `GHSA-vfj7-8cjw-p6xm` остаётся в dev tooling без доступного upstream patch. |

Для браузерного прогона использовалась отдельная `oge_tutor_block3_demo_test` на локальном PostgreSQL; действующая БД приложения не менялась. Тестовые backend/frontend запущены отдельно от пользовательского кабинета. CI и независимая проверка PR ожидаются. Перед реальным развёртыванием нужны снимки БД и файлов, проверка восстановления и расписание бэкапов на VPS; VPS пока нет.
